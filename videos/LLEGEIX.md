# Vídeos de muntatge

Vídeos oficials de muntatge del braç SO-101, de la documentació de LeRobot de Hugging Face:
https://huggingface.co/docs/lerobot/en/so101

| Fitxer | Articulació |
|---|---|
| `Joint1_v2.mp4` | 1 – Base |
| `Joint2_v2.mp4` | 2 – Espatlla |
| `Joint3_v2.mp4` | 3 – Colze |
| `Joint4_v2.mp4` | 4 – Canell |
| `Joint5_v2.mp4` | 5 – Gir del canell |
| `Gripper_v2.mp4` | 6 – Pinça |

La pestanya «Guia» de l'app els obre amb VLC i hi escriu el nom de l'articulació.
Si en falta algun, torna'ls a baixar amb:

```bash
./videos/baixar_videos.sh
```
